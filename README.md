One funny line for make.fun's "One Star, Written in Sap": a one-star
review written by a houseplant about the human who owns it, in a single
line under 280 characters — a real grievance (leftover-coffee watering,
bragged about as "low maintenance") with the punch at the end.

## How to run

```sh
python3 main.py   # writes /output/entry.txt
```

`main.py` uses only the Python standard library, validates the line (one
line, 1–279 characters, not only whitespace), and writes the same bytes
on every run.
